# Embryo Object Store

Embryo Object Store is Embryo-Zero's fork of [seaweedfs](https://github.com/seaweedfs/seaweedfs) (eed00c3, commit eed00c3). It does distributed files and S3 storage.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
